# RotaJá

O RotaJá é um aplicativo desenvolvido em Flutter projetado para conectar empresas/clientes a entregadores de forma eficiente. A plataforma permite que estabelecimentos solicitem serviços de entrega, enquanto os entregadores podem visualizar as demandas disponíveis, aceitar corridas e visualizar a rota em tempo real até o destino.

---

## Objetivo do Projeto

O objetivo do aplicativo é otimizar a logística urbana de entregas, oferecendo:
 Para Empresas/Clientes: Criação de pedidos de entrega com pontos de partida e destino.
 Para Entregadores: Autonomia para escolher quais entregas realizar e acesso a um sistema de navegação por mapas com a melhor rota disponível.

---

## Tecnologias e Dependências

O projeto foi construído utilizando as seguintes ferramentas e pacotes:

### Core & Mapas
 [Flutter](https://flutter.dev/): Framework para desenvolvimento multiplataforma.
 [`flutter_map`](https://pub.dev/packages/flutter_map): Renderização de mapas interativos baseados em OpenStreetMap.
 [`latlong2`](https://pub.dev/packages/latlong2): Utilitários matemáticos para coordenadas geográficas (Latitude e Longitude).
 [`geolocator`](https://pub.dev/packages/geolocator): Acesso aos serviços de localização do dispositivo
